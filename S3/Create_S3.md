# Create S3 Bucket
**Step 1:** Sign In to AWS

**Step 2:** Search for Amazon S3

<ul>
<li>Go to the search bar at the top of the AWS Console </li>
<li>Type S3</li>
<li>Select Amazon S3 from the search results</li>
</ul>

<img width="2870" height="929" alt="image" src="https://github.com/user-attachments/assets/df224c36-9120-429a-80a4-29695e7af693" />

**Step 3: Creation of Bucket**

- Click on **Create bucket**
- Select Bucket type **"General purpose"**
- Select Bucket namespace **"Global namespace"**
- Enter a unique bucket name
  
<img width="2811" height="1209" alt="image" src="https://github.com/user-attachments/assets/99a79e12-d967-4687-926b-118fbd50e1bc" />

**Step 4: Configure Bucket Settings**

- Under **Configure Object Ownership**, keep the default setting **"ACLs disabled"**
- Under **Block Public Access Settings**, keep **"Block all public access"** enabled
- Leave **Bucket Versioning** disabled

<img width="2875" height="1514" alt="image" src="https://github.com/user-attachments/assets/9d5f422c-9869-47fe-a8a6-1a825808b663" />


- Review **Additional Settings**
- Click **Create bucket**
  
<img width="2776" height="1376" alt="image" src="https://github.com/user-attachments/assets/ebbaa8e5-903f-4954-b2c8-ca4b3b35ca64" />


**Step 5: Verify the Created Bucket**

- Return to the **Amazon S3 dashboard**
- Under the **Buckets** section, locate your newly created bucket
